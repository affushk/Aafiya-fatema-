# Aafiya Fatema — V9 Big Realism Polish

A child-friendly Android talking-pet game with an original white cat.

## V9 fixes from the latest test video
- Walking uses a more planted alternating front/back-leg cycle with less vertical floating
- Room destinations are locked, so the cat stops at the intended interaction point
- Food interaction lowers the head closer to the bowl/table position
- Bath pose lowers the cat toward the tub instead of hovering above it
- Sleep pose is lower, flatter and positioned toward the bed contact point
- Camera follow is bounded so the cat is not pushed half off-screen
- Per-room camera zoom/look offsets keep the full body in frame
- Glasses/bow/crown are smaller, track the head more tightly, and hide while walking/bathing/sleeping to prevent floating
- Room contrast/depth improved, including brighter skirting and stronger furniture colors
- Dynamic contact shadow follows the cat and softens during jumps, making movement feel grounded
- Home wandering, touch reactions, scratch marks, cuddle, smile, voice repeat, levels and rewards retained
